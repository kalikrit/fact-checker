# Fact Checker

Автоматический фактчекер: принимает текст на вход, извлекает проверяемое
утверждение, находит источники в сети и выносит вердикт
(истина / ложь / вводит в заблуждение / не проверено).

## Статус

🚧 В разработке. Текущий этап: проектирование модели и use cases.

См. [`docs/MODEL.md`](./docs/MODEL.md) — концептуальная модель фактчекинга.

## Идея

Пользователь вводит текст (одно-два предложения), например:

> Брюс Уиллис заболел раком и скончался. На похоронах актёра
> присутствовали Арнольд Шварценеггер и Сильвестр Сталлоне.

Приложение:

1. Извлекает **главное утверждение** (main) и отделяет детали (attributes).
2. Оценивает **правдоподобность** (plausibility) — может ли такое быть в принципе.
3. Ищет **источники** в сети.
4. Выносит **вердикт** на основе двух сигналов: правдоподобность + доказательства.
5. Показывает **ссылки на источники** и объяснение.

## Принципы

- **Опора на источники**, а не на память LLM.
- **Прозрачность**: пользователь видит, откуда вердикт.
- **Осторожность**: отсутствие источников ≠ ложь. Отдельная категория `unknown`.
- **Детали — условно**: проверяются только если main подтверждён.

## Архитектура (план)

Frontend (Vue 3 SPA)
│
▼
Backend (FastAPI)
│
├── API-слой (routes, DTO)
├── Pipeline (оркестратор шагов)
├── Domain (чистая логика)
└── Infrastructure (LLM, search, DB, cache)
│
├── GigaChat (Cloud.ru)
├── DuckDuckGo + Wikipedia
└── SQLite (история, кэш)


## Стек

- **Backend:** Python 3.11+, FastAPI, Pydantic
- **Frontend:** Vue 3 + TypeScript + Vite
- **LLM:** GigaChat (через Cloud.ru) — с абстракцией для смены провайдера
- **Поиск:** DuckDuckGo + Wikipedia API (без ключей)
- **БД:** SQLite (история проверок, кэш)
- **Тесты:** pytest (backend), Vitest (frontend)
